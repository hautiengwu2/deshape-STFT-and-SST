# deshape-STFT-and-SST
This is matlab code for the de-shape STFT and SST algorithm.

Main reference: Lin, Chen-Yun, Li Su, and Hau-Tieng Wu. "Wave-shape function analysis: When cepstrum meets time–frequency analysis." Journal of Fourier Analysis and Applications 24.2 (2018): 451-505.

One application: Su, Li, and Hau-Tieng Wu. "Extract fetal ECG from single-lead abdominal ECG by de-shape short time Fourier transform and nonlocal median." Frontiers in Applied Mathematics and Statistics 3 (2017): 2.
